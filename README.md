# Telecom Customer Churn Prediction

End-to-end **Machine Learning project** to predict telecom customer churn using advanced feature engineering and logistic regression.

## Features

- ML pipeline with preprocessing
- Feature engineering module
- Model training & evaluation
- Feature importance analysis
- Streamlit interactive dashboard

## Tech Stack

- **Python**
- **Scikit-learn**
- **Pandas**
- **Streamlit**
- **Git & GitHub**

## Business Impact

Helps telecom companies identify **high-risk customers** and take proactive retention actions.

## Model Performance

- ROC-AUC Score: ~0.65
- Logistic Regression Model
- Business threshold tuning applied

## How to Run Locally

```bash
git clone https://github.com/AkashAnkushe/telecom-churn-prediction.git
cd telecom-churn-prediction
pip install -r requirements.txt
streamlit run app/app.py
```

## Project Structure

app/        → Streamlit dashboard  
src/        → ML pipeline & model code  
models/     → Saved trained model  
notebooks/  → EDA & validation  
data/       → Dataset
